Bookmarks are in the sidebar now: bookmark any folder or file from the context menu or with the "+" in the Bookmarks header, give it a name, and sort it into groups. Groups can be created, renamed, reordered and deleted (their items move to Ungrouped, never deleted). Click a folder bookmark to go there, click a file bookmark to open it. Bookmarks live in `data\bookmarks.json` next to the exe, and missing ones stay listed, dimmed, until removed.

<!-- zh-TW -->
側邊欄現在有書籤：用右鍵選單或書籤標題旁的「+」，把任何資料夾或檔案加入書籤、命名，再分進群組。群組可以新增、重新命名、排序和刪除（裡面的項目會移到未分組，不會被刪掉）。點資料夾書籤會前往該處，點檔案書籤會用預設程式開啟。書籤存在 exe 旁邊 `data\bookmarks.json`，找不到的項目會以淡色留在清單中，直到你移除它。

<!-- zh-CN -->
侧边栏现在有书签：用右键菜单或书签标题旁的「+」，把任何文件夹或文件加入书签、命名，再分进分组。分组可以新建、重命名、排序和删除（里面的项目会移到未分组，不会被删掉）。点文件夹书签会前往该处，点文件书签会用默认程序打开。书签存在 exe 旁边的 `data\bookmarks.json`，找不到的项目会以淡色留在清单中，直到你移除它。
